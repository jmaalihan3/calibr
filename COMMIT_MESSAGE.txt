Implement revised exam format with expandable results and misconception feedback

This commit implements the revised JSON exam format as specified in
statcal_exam_json_format_guide.md with the following enhancements:

NEW FEATURES:
- Expandable/collapsible question cards in results display
- Rich explanations for each answer choice
- Misconception feedback displayed ONLY for incorrect answers
- Learning objectives and related concepts for each question
- Review titles used as expandable dropdown headers

BACKEND CHANGES:
- Added choices_json and review_json columns to questions table
- Created load_revised_exam.py to handle new JSON format
- Updated db.get_random_questions() to include new fields
- Updated db.get_exam_with_answers() to include new fields
- Updated services layer to pass choices and review to frontend
- Maintained full backward compatibility with old format

FRONTEND CHANGES:
- Redesigned results from table-based to expandable card layout
- Each question displays in a collapsible dropdown
- Color-coded headers (green for correct, red for incorrect)
- Shows correct answer explanation for all questions
- Shows misconception explanation only for selected incorrect answer
- Displays learning objectives and related concepts as tags
- Added toggleQuestion() function for expand/collapse
- Responsive design maintained for mobile devices

DATABASE SCHEMA:
- questions.choices_json: TEXT - Complete choices array with explanations
- questions.review_json: TEXT - Review metadata (title, objectives, concepts)
- questions.topic: TEXT - Question topic
- questions.explanation: TEXT - Legacy field for compatibility
